# market-table-research

一个面向 Codex 等 AI Agent 的中文市场调研 Skill。它先固定目标人群、核心需求与产品方向，再通过公开来源完成多来源核验，输出结论优先、产品图可见、证据可追溯的 Word、Excel 或 Markdown 报告。

## 适合处理

- 产品、品牌、竞品与替代方案调研
- 指定人群的消费偏好与生活方式调研
- 软件、硬件、软硬件结合、服务、内容、社区与实体消费品调研
- 价格、销量、下载量、发布时间、团队、社媒与媒体评测核验
- 产品级用户画像、销售方式、营销与运营策略整理

## 核心原则

1. 先定人群、需求和产品方向，再搜索产品。
2. 官网、官方商城、应用商店与公司公告优先。
3. 关键事实保留原始链接、来源层级与访问日期。
4. 软件看下载量、日活或月活；硬件看销量、出货量或订单量，不混用口径。
5. 产品图必须直接嵌入报告，不用图片链接或占位图糊弄。
6. 官网失效、产品下线、无法核验或没有可靠评测的候选项不包装成有效样本。
7. 找不到可靠证据的字段统一写 `/`，不猜测。
8. 事实、判断与建议分离，交付前通过来源、链接、字段和版式质量门槛。

## 安装

将整个仓库克隆或复制到你的 Agent 可读取的 Skill 目录，保持目录结构不变。不同 Agent 的安装位置与调用方法不同，请以对应产品的官方文档为准。

```bash
git clone https://github.com/luqi67677/market-table-research.git
```

安装完成后，可用自然语言或显式名称调用：

```text
使用 $market-table-research 调研中国 16—23 岁女性偏爱的首饰品牌，
输出 Word 报告，产品图直接嵌入，并保留可点击来源与访问日期。
```

## 输出要求

- Word：白底、少色、连续流式排版；长表拆分；逐页检查空页、大块空白、表格截断和图片缺失。
- Excel：统一字段、可筛选、图片与来源对应。
- Markdown：图片必须实际渲染，不能只显示路径或 Base64 文本。
- 用户要求“只要一张表”时，不追加无关方法论或泛化建议。

## 运行条件

- 支持本地 Skill 的 AI Agent
- 可访问公开网页的浏览能力
- 生成 Word、Excel 或 Markdown 所需的对应文档工具
- 本 Skill 本身不要求 API Key，也不包含用户数据或密钥
